# The Portugal Guide

A lightweight, responsive first version of The Portugal Guide website.

## Files
- `index.html` — homepage structure and copy
- `styles.css` — responsive editorial styling
- `script.js` — mobile navigation and footer year

## Publish with GitHub Pages (free)
1. Upload these four files to the root of the `main` branch of `edicruz603-stack/the-portugal-guide`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. GitHub will provide the public website address when deployment is ready.

## Before launch
- Replace the temporary image placeholders in `styles.css` with verified image URLs you have permission to use commercially.
- Add a real contact email and legal/privacy pages before collecting customer information or selling products.
- The Sintra guide is marked as in preparation. No checkout or paid service is connected.
- No domain, subscription, or paid service is required for this prototype.
