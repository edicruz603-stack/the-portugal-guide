# The Portugal Guide

A lightweight, responsive first version of The Portugal Guide website.

## Live website
https://edicruz603-stack.github.io/the-portugal-guide/

## Files
- `index.html` — homepage structure and copy
- `sintra.html` — practical destination field guide with itineraries, transport, food stops, map links, ticket guidance and credited photography
- `styles.css` — responsive editorial styling and CSS gradient artwork, including the Sintra guide
- `script.js` — mobile navigation and footer year

## Publishing
The site is published with GitHub Pages from the `main` branch, using the repository root (`/`). Hosting is free.

## Current status
