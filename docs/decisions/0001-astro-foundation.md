# ADR 0001 — Astro + TypeScript foundation, legacy URLs preserved

Date: 7 November 2026 · Status: accepted by owner and ChatGPT (technical review); implemented in Phase 0 + 1.

## Context
The site was five hand-written HTML pages with copy-pasted header/footer, inline styles and scripts, no build, no tests, and `main` = production. The approved target is a multi-destination platform with content separated from presentation.

## Decision
- Astro (static output) + TypeScript strict; Zod validation; Vitest; Playwright; GitHub Actions.
- `build.format: 'file'` and the existing base path so every live URL is unchanged; no redirects needed.
- Phase 1 ports pages faithfully (generated by `scripts/port-legacy.mjs`, verified by `scripts/check-parity.mjs`); structured content replaces the ported markup in Phase 2.
- Maps go through a `MapAdapter` interface; Leaflet is the first adapter. Public OSM tiles are used only for normal interactive viewing.
- No previews (owner decision, 7 Nov 2026): CI uploads test results and technical reports only, never the built site. Production is released once, after final validation and owner approval.
- Validation levels: critical (blocks build), warning, editorial pending.

## Consequences
- Production keeps serving the legacy files until a separate cut-over approval.
- Page-specific legacy CSS remains (scoped per page) until Phase 2 componentises sections.
- The host can change later through `SITE_URL` / `BASE_PATH` without code changes.
